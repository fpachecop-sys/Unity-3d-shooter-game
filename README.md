# Proyecto: Videojuego Shooter 3D en Tercera Persona

Este es un proyecto interactivo desarrollado en Unity 3D que implementa mecánicas avanzadas de disparo en tercera persona, control de físicas, animaciones y diseño de niveles.
Proyecto elaborado de forma independiente.

## Tecnologías y Herramientas Utilizadas
* **Motor Gráfico:** Unity 3D
* **Lenguaje de Programación:** C# (Arquitectura Orientada a Objetos)
* **Componentes:** Unity Physics (Manejo de colisiones y gravedad), Animator, Cinemachine (Control de cámara en tercera persona).

## Características del Proyecto
* **Mecánicas de Juego:** Sistema de apuntado, disparo, recarga y movimiento fluido del personaje en un entorno tridimensional.
* **Inteligencia Artificial:** Enemigos con comportamiento básico de persecución y ataque basados en NavMesh.
* **Interfaz de Usuario (UI):** Menú principal, barras de vida, contador de munición y pantalla de fin del juego (Game Over).
